# The project's work items

A work item is a piece of work with a written spec and plan. It lives in a folder, under
`open/` while it is open and under `closed/` afterwards: a `README.md` for humans, the
spec, the plans and, once it closes, `closing.md`.

The index is the only part of this record that gets rewritten. The checkboxes in the
plans stay unticked: the state is kept here.

A work item closes only when every leftover has somewhere to go: done, dropped with the
reason written down, or put on the backlog. The forms are in the `documentation` skill,
in `references/details.md`.
