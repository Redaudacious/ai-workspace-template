### Task 1: the test, then the script

**Who:** session — no local worker: the exercise must work on a machine without one too.
**Verifier:** `bash tests/test-greeting.sh` prints `✓ 2 tests passed`.

**Files:** create `tests/test-greeting.sh`, `greeting.sh`.

- [ ] **Step 1: the test, which fails because the script does not exist**

`tests/test-greeting.sh`, with the execute bit (`chmod 755`):

```bash
#!/bin/bash
# test-greeting.sh — the test of greeting.sh: the greeting, and the use without a name.
set -u
S="$(cd "$(dirname "$0")/.." && pwd)/greeting.sh"
[ "$("$S" Ana 2>/dev/null)" = "hello, Ana" ] || { echo "✗ the greeting is missing"; exit 1; }
"$S" >/dev/null 2>&1
[ $? -eq 2 ] || { echo "✗ without a name, the code must be 2"; exit 1; }
echo "✓ 2 tests passed"
```

```bash
bash tests/test-greeting.sh; echo "code=$?"
```

Expected: `✗ the greeting is missing`, `code=1`.

- [ ] **Step 2: the script**

`greeting.sh`, with the execute bit:

```bash
#!/bin/bash
# greeting.sh — prints "hello, <name>". Without a name, says how it is used and exits with 2.
[ $# -eq 1 ] || { echo "usage: greeting.sh <name>" >&2; exit 2; }
echo "hello, $1"
```

- [ ] **Step 3: the test, which passes**

```bash
bash tests/test-greeting.sh && ./greeting.sh Ana
```

Expected: `✓ 2 tests passed`, then `hello, Ana`.

- [ ] **Step 4: the commit**

```bash
git add greeting.sh tests/test-greeting.sh && git commit -m "The greeting has its test first, then the script, so that a call without a name fails with a sign instead of greeting nobody"
```
